# LongMemEval-S: NeuroSym Versus Graphiti on Shared Extracted Facts (250 Histories)

This evaluation compares NeuroSym hybrid KG memory with Graphiti on 250 LongMemEval-S histories. Both systems ingest the same extracted facts, and each answer is scored by a judge.

## Exact accuracy

| Arm | Correct | Accuracy | 95% Wilson CI |
|---|---:|---:|---:|
| NeuroSym hybrid KG, shared facts | 134/250 | 53.6% | 47.4–59.7% |
| Graphiti, shared facts | 131/250 | 52.4% | 46.2–58.5% |

| Paired outcome | Histories |
|---|---:|
| Both correct | 116 |
| NeuroSym only correct | 18 |
| Graphiti only correct | 15 |
| Both wrong | 101 |

The paired NeuroSym-minus-Graphiti difference is +1.2 percentage points, 95% paired bootstrap CI [−3.2, +5.6], exact McNemar p=0.73. No difference was detected between the two arms. The interval is consistent with differences from about −3 to about +6 points; it is not an equivalence test. Excluding abstention questions gives +1.7 points, 95% CI [−2.6, +6.5] (n=231).

## Scope

The 250 histories are a subset of the 500 LongMemEval-S questions. They are the histories that completed the shared extraction and both memory arms, so the subset was determined neither by correctness nor by random sampling; multi-session and temporal-reasoning questions are under-represented relative to the full benchmark (15.6% and 18.0% of this set versus 24.2% and 25.4% of the 500).
Both arms ingest the same extracted facts. The Graphiti arm does not perform its own extraction, so this is a different contrast from the Graphiti arm in the [matched Kimi A/B persona benchmark](../persona_joint_kimi_ab_a100_build1/README.md), and the difference does not isolate Scallop validation.
Answers were scored with the official LongMemEval judge prompts using a local Qwen3.5-4B judge rather than the official GPT-4o judge, so absolute accuracies are not directly comparable to published LongMemEval numbers.

The knowledge-update bootstrap interval excludes zero, but it rests on four discordant pairs (McNemar p=0.125) among many subgroups, so it is not a finding. [`comparisons.csv`](comparisons.csv) also breaks results down by dataset question type.

The scorer's other metrics on these 250 histories: task-averaged accuracy 51.1% (NeuroSym) and 49.5% (Graphiti); population-weighted accuracy, which reweights strata to the full 500, 49.5% and 48.7%.

## Metric definitions

- **Unit:** one question per history; each arm produces one answer, judged once.
- **Correct:** the judge's response contains "yes" (case-insensitive). Prompts are the verbatim LongMemEval `get_anscheck_prompt` templates, including the abstention, temporal off-by-one, knowledge-update, and preference variants. A pipeline failure would count as incorrect; none occurred in these 250 histories.
- **Uncertainty:** two-sided 95% Wilson intervals per arm; 95% percentile bootstrap over histories for the paired difference (10,000 resamples, seed 20261114); exact two-sided McNemar test.

## Models and data

- Dataset: `xiaowu0162/longmemeval-cleaned`, `longmemeval_s_cleaned`, revision `98d7416c24c778c2fee6e6f3006e7a073259d48f`.
- Shared fact extraction and answer generation: `Qwen/Qwen3.5-4B`, revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`.
- Embeddings: `BAAI/bge-small-en-v1.5`, revision `5c38ec7c405ec4b44b94cc5a9bb96e735b38267a`. Graphiti: `graphiti-core` 0.29.3.
- Judge: `Qwen/Qwen3.5-4B`, temperature 0, at most 10 output tokens, thinking disabled; the judge revision was not recorded. The official LongMemEval judge is `gpt-4o-2024-08-06`.
