## Directory Purposes

**Repo root (flat by design):**
- Purpose: Top-level scripts that are *both* entry points and importable libraries (`longbench_kg_pipeline`, `neo4j_graph`, `scallop_validator` are imported by `experiments/build_kg.py` and `experiments/graph_context.py`).
- Contains: One file per architectural layer (KG pipeline, KG store, validator) plus legacy single-purpose evaluators.
- Key files: `longbench_kg_pipeline.py`, `neo4j_graph.py`, `scallop_validator.py`.

**`experiments/`:**
- Purpose: Unified 2x3 ablation harness. Lazy imports keep `common.py` and `aggregate.py` runnable without `neo4j`/`rlm`/`openai`/`scallopy` installed.
- Contains: shared CLI, orchestrator, KG builder, answerers, graph-source abstraction, aggregator.
- Key files: `experiments/_cli.py` (the only place per-example flow lives), `experiments/common.py` (single source of truth for cell metadata + result schema).

**`experiments/cells/`:**
- Purpose: One 20-line shim per ablation cell. Pure delegation; no logic.
- Pattern: each defines `CELL_ID`, `LABEL`, optional `SESSION`, then calls `run_cell(kind=, retrieval=, session_id=, argv=)`.

**`tests/`:**
- Purpose: Unit + smoke tests; no network or live Neo4j/vLLM required.
- Pattern: each test file is runnable directly with `python tests/test_*.py`; smoke test mocks `openai.OpenAI`.

**`tests/fixtures/`:**
- Purpose: Sample verified-facts JSONL used by tests.
- Note: explicitly whitelisted in `.gitignore` (`!tests/fixtures/*.jsonl`).

**`results/`:**
- Purpose: Generated outputs from `experiments/run_all.py` and `experiments/aggregate.py`.
- Generated: Yes (every cell run writes its own `results/cell{N}_{label}/results.jsonl`).
- Committed: Only `summary.csv` and `figures/accuracy_grid.png` are tracked (per-cell `.jsonl`s are excluded by `*.jsonl` in `.gitignore`).

**`.planning/codebase/`:**
- Purpose: GSD codebase-map documents (this file + `ARCHITECTURE.md`).
- Generated: Yes (by `/gsd-map-codebase`).

## Key File Locations

**Entry Points:**
- `download_longbench.py`: HuggingFace LongBench-v2 → `data.jsonl`.
- `longbench_kg_pipeline.py`: full extract → verify → Neo4j pipeline.
- `evaluate.py`: legacy flat evaluator with `--mode {kg,raw}`.
- `rlm_baseline.py`: legacy raw-context RLM.
- `rlm_graph_baseline.py`: legacy KG-context RLM (Neo4j + JSONL fallback).
- `experiments/run_all.py`: orchestrator for all 6 cells.
- `experiments/build_kg.py`: one-session KG builder.
- `experiments/aggregate.py`: results → CSV + figure.
- `experiments/cells/cell{1..6}_*.py`: single-cell runners.
- `scallop_validator.py` (when invoked directly): in-file Scallop rule test suite.

**Core Libraries (importable, no top-level side effects):**
- `neo4j_graph.py`: `Neo4jGraph` class + `sanitize_predicate` helper.
- `scallop_validator.py`: `validate_update`, `confidence_score`, `FUNCTIONAL_PREDICATES`, `GENERIC_OBJECTS`.
- `longbench_kg_pipeline.py`: `LongBenchKGPipeline`, `PipelineConfig`, plus pure helpers `flatten_context_to_sentence_records`, `chunk_sentence_records`, `make_fact_id`, `normalize_status`, `sanitize_predicate`, `parse_json_object`.
- `experiments/common.py`: `CELLS`, `CELL_SCHEMA`, `cell_output_path`, `iter_pilot_examples`, `format_question`, `extract_letter`, `write_result_row`, `truncate_context`.
- `experiments/graph_context.py`: `GraphSource`, `open_graph_source`, `extract_seed_entities`.
- `experiments/flat_answerer.py`: `flat_answer`.
- `experiments/rlm_answerer.py`: `make_rlm`, `rlm_answer`.

**Configuration:**
- `requirements.txt`: pinned deps and Python-version-split commentary for scallopy/rlms.
- `.gitignore`: excludes `data.jsonl`, generic `*.jsonl`, `vllm/`, etc.
- No `.env`, no YAML, no `pyproject.toml`, no `setup.py` — everything is CLI flags or `os.getenv` (`NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD`, `NEO4J_SESSION_ID`, `NEO4J_DATABASE`, `VLLM_API_KEY`).

**Generated / Outputs:**
- `data.jsonl` (LongBench-v2 dump, root, gitignored).
- `verified_facts.jsonl` (default `--output` of `longbench_kg_pipeline.py`, gitignored).
- `results/kg_builds/<session>_facts.jsonl` (KG mirror; offline fallback for KG cells).
- `results/cell{N}_<label>/results.jsonl` (per-cell per-example records).
- `results/summary.csv`, `results/figures/accuracy_grid.png` (aggregator outputs).
- `rlm_logs*/` directories (RLMLogger traces).
- `smoke_output.jsonl`, `verified_facts_test.jsonl` (legacy test outputs, explicitly gitignored).

**Testing:**
- `tests/test_pipeline_smoke.py` — full pipeline e2e with mocked LLM (no vLLM/Neo4j needed).
- `tests/test_validation.py` — verification prompt structure, status normalization.
- `tests/test_neo4j_format.py` — Cypher generation, predicate sanitization, fact_id stability.
- `tests/test_neo4j_graph.py` — `Neo4jGraph` against a mocked driver.
- `tests/fixtures/verified_facts.sample.jsonl` — sample fact rows.

## Naming Conventions

**Files:**
- Module files: `snake_case.py`. Multi-word top-level entry points are full names (`longbench_kg_pipeline.py`, `rlm_graph_baseline.py`), not abbreviations.
- Cell modules: `cell{N}_{flat|rlm}_{raw|kg}[_{scallop|noscallop}].py` — number, kind, retrieval, validator. Single source of truth for labels is `CELLS` in `experiments/common.py:31`.
- Tests: `tests/test_*.py`.
- Scratch / demo: leading underscore (`_demo_neo4j.py`) or generic name (`test.py`, `test.scl`).

**Directories:**
- `experiments/` for the production harness; `experiments/cells/` for the cell shims.
- `tests/` for tests, `tests/fixtures/` for committed sample data.
- `results/cell{N}_{label}/` mirrors `cell_output_path()` in `experiments/common.py:41`.
- KG sessions follow `pilot_{scallop|noscallop}` (`experiments/run_all.py:28`).

**Code:**
- KG fact predicates: `UPPER_SNAKE_CASE` (sanitized by `sanitize_predicate` in both `longbench_kg_pipeline.py:532` and `neo4j_graph.py:50`).
- Python identifiers: PEP 8 (`snake_case` functions, `PascalCase` classes, `UPPER_SNAKE_CASE` module constants).
- Argparse flags: `--kebab-case` (e.g. `--vllm-base-url`, `--neo4j-uri`, `--max-tokens`, `--limit-triples`).
- Env vars: `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD`, `NEO4J_DATABASE`, `NEO4J_SESSION_ID`, `VLLM_API_KEY`.
- Cell IDs: stable integers 1-6 used as both directory prefix and CSV column key.

## Where to Add New Code

**New ablation cell:**
- Add a row to `CELLS` in `experiments/common.py:31`.
- Create `experiments/cells/cell{N}_{label}.py` mirroring `cell6_rlm_kg_scallop.py` (delegate to `run_cell`).
- If it needs a new `(kind, retrieval)` combination, extend `experiments/_cli.py:run_cell` plus a new answerer in `experiments/`.
- Add the cell to `experiments/aggregate.py:render_figure`'s `columns` list if it should appear in the bar chart.

**New retrieval mode:**
- Mirror `GraphSource` in `experiments/graph_context.py`: implement `context_for(ex, ...) -> (str, int)` and a `close()` method.
- Wire it up in `experiments/_cli.py:run_cell` next to the existing `retrieval == "kg"` branch.

**New answerer (e.g. an Anthropic backend):**
- Add a new module under `experiments/`, e.g. `experiments/anthropic_answerer.py`, mirroring the `flat_answerer.py` / `rlm_answerer.py` shape `(client, model, context, question) -> (letter, raw, error?)`.
- Add the dispatch in `experiments/_cli.py:run_cell` under the `if kind == ...` block.

**New KG validation rule:**
- Pure-Python guard: prepend to the "Python-side checks" block in `scallop_validator.py:49`.
- Scallop rule: add an `ctx.add_rule(...)` line in `validate_update` (`scallop_validator.py:75`) and probe its relation after `ctx.run()`. Add a test case in the `__main__` block at the bottom of the file.

**New Cypher query / write:**
- Put it on `Neo4jGraph` in `neo4j_graph.py` (do not embed Cypher elsewhere). Use `_session()` and parameterized `session.run(...)`. Sanitize predicates with `sanitize_predicate(...)`.

**New metric in the summary:**
- Add a key to `_summarize_rows` in `experiments/aggregate.py:39`.
- Add the column name to `SUMMARY_COLUMNS` (`experiments/aggregate.py:22`).
- Optionally update `render_figure` to plot it.

**New result-row field:**
- Add the key to `CELL_SCHEMA` in `experiments/common.py:16`.
- Pass it in the `write_result_row(...)` call in `experiments/_cli.py:198`.
- All existing rows default to `None` for missing keys, so this is forward-compatible.

**New test:**
- Place in `tests/` as `test_*.py`. Mock `openai.OpenAI` and/or `neo4j.GraphDatabase` (see `tests/test_pipeline_smoke.py` for the pattern). Use `tests/fixtures/` for any committed sample inputs.

**New dataset:**
- Add a downloader analogous to `download_longbench.py` (atomic temp-file write, ASCII-safe JSON, per-field validation pass).
- Update `flatten_context_to_sentence_records` in `longbench_kg_pipeline.py:299` if the context shape differs from a string or HotPotQA-style nested list.

## Special Directories

**`vllm/`:**
- Purpose: in-tree vLLM source checkout used by `test.py` to bypass the installed package.
- Generated: No (developer-checked-out; see `test.py:5`).
- Committed: No (explicitly listed in `.gitignore`).

**`rlm_logs*/`:**
- Purpose: `RLMLogger` write target for RLM internal traces.
- Generated: Yes (by `rlm_baseline.py`, `rlm_graph_baseline.py`, and `experiments/_cli.py`).
- Committed: No.

**`results/`:**
- Purpose: All cell outputs + aggregator outputs.
- Generated: Yes.
- Committed: Partial — `summary.csv` and `figures/` are tracked; per-cell `.jsonl`s are gitignored.
